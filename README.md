# リバース予算・自由支出プランナー

「先に貯蓄・投資を確保してから残額を自由に使う」リバース予算法に基づく家計プランナー。

## 機能
- 月収（手取り）・貯蓄率・投資率をスライダーで入力
- 貯蓄額・投資額・自由支出額をバーグラフで可視化
- 自由支出の1日あたり予算を表示
- カテゴリ別支出シミュレーション（家賃・食費・交通費等 6カテゴリ）
- 貯蓄目標達成月数シミュレーション
- 設定を localStorage に保存

## リバース予算法とは
従来の「収入 - 支出 = 貯蓄」ではなく、「収入 - 貯蓄/投資 = 自由支出」の順で計算する方法。先取り貯蓄を自動化することで、貯蓄を確実に積み立てながら残額を罪悪感なく使えます。
